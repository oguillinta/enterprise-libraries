# lib-date-utils

Framework-independent date utility library providing reusable static operations for common date and time handling in Java applications.

## Features

- Past-date validation
- Expiration validation using `YearMonth`
- Day difference calculation
- Latest-date comparison
- Deterministic time-based operations using `Clock`
- Pure Java implementation
- No Spring or framework dependencies
- Static utility API
- Java 25 compatible

## Requirements

- Java 25
- Maven 3.9+ or compatible build tool

## Installation

### Maven

```xml
<dependency>
    <groupId>pe.com.galaxy.enterprise.java.libs</groupId>
    <artifactId>lib-date-utils</artifactId>
    <version>1.0.0</version>
</dependency>

# lib-string-utils

Framework-independent string utility library providing reusable static operations for common text handling in Java applications.

## Features

- Blank string validation
- Whitespace normalization
- Conversion of blank values to `null`
- String truncation
- Default value handling
- Pure Java implementation
- No Spring or framework dependencies
- Static utility API
- Java 25 compatible

## Requirements

- Java 25
- Maven 3.9+ or compatible build tool

## Installation

### Maven

```xml
<dependency>
    <groupId>pe.com.galaxy.enterprise.java.libs</groupId>
    <artifactId>lib-string-utils</artifactId>
    <version>1.0.0</version>
</dependency>
